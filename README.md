# CodeAlpha AI Chatbot

A Java-based AI chatbot that uses keyword-based intent detection to understand user messages and provide relevant responses.

## Features

- Interactive console-based chatbot
- Natural language-style user input
- Intent detection system
- Multiple chatbot responses
- Random responses for greetings
- Handles unknown questions
- Conversation history
- Clear conversation history
- Displays current date
- Displays current time
- Provides Java-related information
- Provides CodeAlpha-related information
- Input validation
- Object-Oriented Programming design

## Technologies Used

- Java
- Object-Oriented Programming
- Enum
- Collections Framework
- Java Date and Time API
- Exception Handling
- Random Response Generation
